# Syntax Arcade game suggestions

[Syntax Arcade](https://www.syntaxarcade.games/) is a hand-picked list of games in which writing code is the main thing you do. This repository is where you can suggest games for it.

## Suggest a game

1. Check that the game isn't already listed on [syntaxarcade.games](https://www.syntaxarcade.games/).
2. Search the [open issues](https://github.com/syntax-arcade/games/issues) to see whether someone has suggested it already. If so, add a comment or a 👍 instead of opening a new one.
3. [Open a new suggestion](https://github.com/syntax-arcade/games/issues/new?template=suggest-a-game.yml) and fill in the form. The most useful part is a short description of how you write code in the game.

Suggestions for changes are welcome too, for example when a game is in the wrong category, a link is broken or a game has become free.

## The rule

A game is listed when writing code is its primary verb, and when that code is part of the game's own premise.

- **Code is the main activity.** Most of your time goes into writing, reading or fixing programs, not into shooting, building or exploring.
- **Code belongs to the game.** The programming is what the game is about, not a scripting layer or mod added on top of a game with a different story.
- **Any kind of code counts.** Real languages, languages invented for the game, visual blocks and logic circuits all qualify, as long as you are building the logic yourself.

Free browser games and commercial titles are both welcome.

## What is left out

- **Scripting layers and mods.** Minecraft redstone, Roblox, Garry's Mod, Factorio circuits, kOS in Kerbal Space Program and the programmable blocks in Space Engineers all let you program, but the games themselves are about something else.
- **Games about computers where you don't write code.** Papers, Please, Orwell and Duskers have terminals and systems, but you operate them rather than program them.

## The borderline tier

Some games come close to the rule without quite meeting it: you type commands instead of writing programs, you build machines on a timeline, you rearrange rules instead of code, or the coding sits alongside an action game. These are listed and marked as borderline, with a short reason, instead of being dropped silently. Examples are Opus Magnum, Uplink, Hacknet, Hack 'n' Slash, Net.Attack() and Baba Is You.

If you are unsure whether a game fits, suggest it anyway and say why. A borderline game is still worth listing.

## Categories

A game can belong to more than one of these:

- **Code puzzlers:** solve tasks in a given language, with puzzles that get harder.
- **Automation and optimization sims:** code replaces manual work inside a game built for it.
- **Competitive bot programming:** write the AI, then your bots compete.
- **Hacker fiction with real scripting:** the fantasy is hacking, and you actually write scripts.
- **World-hackers:** change the game world by rewriting its code or rules.
- **Learn-to-code games:** games that teach programming, usually in a real language.
- **Build-a-computer:** start from logic gates and work up to a working computer.
- **Action and hybrid:** code mixed with another genre, such as action.

## How entries are checked

- **Free or paid only.** Prices change too often, so the site only says whether a game is free or paid.
- **Last verified.** Each game page shows when its platforms and cost were last checked against the store or the game's site.
- **No advertising.** Listing a game does not mean it is endorsed.
